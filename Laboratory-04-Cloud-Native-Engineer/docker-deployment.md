# List Running Containers

docker ps

*This command lists all Docker containers that are currently running.

# Stop the Running Container

docker stop nginx-server

*This command stops the running Nginx container.

# Verify the Container is Stopped

docker ps

*This command checks whether the Nginx container is still running.

# Remove the Container Completely

docker rm nginx-server

*This command removes the stopped Nginx container completely.

# Summary

In this activity, I learned how to manage the basic lifecycle of a Docker container. I practiced listing, stopping, checking, and removing a container using Docker commands. These commands helped me understand how containers can be easily managed after they are deployed.
