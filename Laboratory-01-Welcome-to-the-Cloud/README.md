# Laboratory 01 - Welcome to the Cloud

## Mission Overview

This laboratory introduces the fundamentals of cloud computing through a Linux-based environment. The activity provides hands-on experience with the command line, user management, system information, file organization, and documentation.

## Objectives

- Understand the basics of a Linux environment.
- Create and manage a Linux user.
- Explore system information.
- Create and organize directories and files.
- Document laboratory activities using Markdown.

## Activities Performed

- Created a Linux user account.
- Verified the username, working directory, and hostname.
- Collected Linux system information.
- Created a workspace directory structure.
- Created and viewed Markdown files.
- Documented the laboratory activities.

## Skills Learned

I learned how to navigate and work with a Linux terminal, create and manage users, gather system information, organize files and directories, and document technical activities using Markdown.
